📘 Machine Learning Notes – Supervised vs Unsupervised Learning
Machine Learning (ML)

Definition:

Machine Learning ek aisi technique hai jisme computer data se patterns seekhta hai aur bina manually rules likhe prediction ya decision leta hai.

Formula:

Data → Learn Pattern → Prediction/Decision
1. Supervised Learning
Definition

Supervised Learning me model ko Input (Features) aur Correct Output (Label) dono diye jaate hain.

Model input aur output ke beech relationship seekhta hai aur naye data par prediction karta hai.

Input + Correct Answer
        ↓
    Model Training
        ↓
 Future Prediction
Example
House Size	Price
1000 sqft	₹50L
1200 sqft	₹60L
1500 sqft	₹80L

Input:

House Size

Output (Label):

House Price

Naya Input:

1300 sqft

Prediction:

≈ ₹65L
Real-Life Examples
Spam Detection
House Price Prediction
Loan Approval
Disease Prediction
Stock Price Prediction
Types of Supervised Learning
1. Classification

Output ek category hota hai.

Examples:

Spam / Not Spam

Cat / Dog

Fraud / Not Fraud
2. Regression

Output ek continuous numerical value hota hai.

Examples:

House Price

Temperature

Gold Price
2. Unsupervised Learning
Definition

Unsupervised Learning me model ko sirf Input Data diya jaata hai.

Koi Label (Correct Answer) nahi hota.

Model khud data me hidden patterns ya groups discover karta hai.

Only Input Data
        ↓
 Model Finds Patterns
        ↓
    Similar Groups
Important Point ⭐

Model ko categories ke naam nahi pata hote.

Wo sirf similar data ko ek group me rakh deta hai.

Supervised vs Unsupervised
Supervised Learning	Unsupervised Learning
Labels available	No labels
Correct answer known	Correct answer unknown
Predicts output	Finds hidden patterns
Learns from examples	Learns from similarities
Used for prediction	Used for grouping and pattern discovery

Key Points (Interview Revision)
Machine Learning = Data se learning.
Supervised Learning = Features + Labels.
Unsupervised Learning = Only Features (No Labels).
Supervised ka goal = Prediction.
Unsupervised ka goal = Pattern Discovery / Clustering.
Classification → Category predict karta hai.
Regression → Numerical value predict karta hai.
Clustering → Similar data ko groups me divide karta hai.
Unsupervised model categories ke naam nahi jaanta, sirf similar data ko clusters me organize karta hai.
One-Line Revision

Supervised Learning: "Model ko question aur answer dono milte hain, isliye wo prediction karna seekhta hai."

Unsupervised Learning: "Model ko sirf data milta hai, isliye wo khud hidden patterns aur groups discover karta hai."
