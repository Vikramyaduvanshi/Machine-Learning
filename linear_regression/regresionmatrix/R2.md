# R² Score (Coefficient of Determination) - Notes

## 1. R² kya sawaal poochta hai?

MSE, RMSE, MAE **absolute error** batate hain. R² ek **relative** sawaal poochta hai:

**"Mera model, sabse simple baseline se kitna behtar hai?"**

---

## 2. MSE akela kaafi kyu nahi?

- MSE = 16.67 accha hai ya bura? Yeh **data ke scale par depend** karta hai.
- y ki values 30 se 50 ke beech hon toh theek-thaak, 1000 se 1001 ke beech hon toh bahut bura.
- Isliye ek **relative** measure chahiye.

---

## 3. Baseline model

Koi feature na pata ho toh sabse safe prediction: **hamesha y ka mean**.

$$\bar{y} = \frac{1}{n}\sum y_i$$

Jo model is baseline se behtar nahi, woh bekaar hai.

---

## 4. Do alag errors

**SS_res** (model ki galti):

$$SS_{res} = \sum (y_i - \hat{y}_i)^2$$

**SS_tot** (baseline / mean ki galti):

$$SS_{tot} = \sum (y_i - \bar{y})^2$$

SS_tot = data apne mean se kitna spread hai (variance ka unnormalized version).

---

## 5. R² ka formula

$$R^2 = 1 - \frac{SS_{res}}{SS_{tot}}$$

**Intuition:** SS_res / SS_tot = "model ki galti, baseline ki galti ka kitna hissa". 1 se ghatane par milta hai ki **model ne kitni galti khatam kar di**.

MSE ke terms mein (n cancel ho jata hai):

$$R^2 = 1 - \frac{\text{MSE}_{model}}{\text{MSE}_{baseline}} = 1 - \frac{\text{MSE}}{\text{Var}(y)}$$

---

## 6. Numerical example

| Sample | Actual y | Predicted ŷ |
|---|---|---|
| 1 | 50 | 45 |
| 2 | 30 | 35 |
| 3 | 40 | 40 |

- Mean: ȳ = (50 + 30 + 40) / 3 = **40**
- SS_res = 5² + (-5)² + 0² = **50**
- SS_tot = 10² + (-10)² + 0² = **200**

$$R^2 = 1 - \frac{50}{200} = 0.75$$

**Matlab:** model ne baseline ki **75% galti khatam** kar di, ya "y ki **variance ka 75%** explain karta hai."

---

## 7. R² ki value ka matlab

| R² | Matlab |
|---|---|
| **1** | Perfect model (SS_res = 0) |
| **0** | Model bas mean predict karne jitna accha |
| **0 se 1** | Model baseline se behtar |
| **Negative** | Model **mean se bhi bura** |

**Negative R² example:** ŷ = [30, 40, 50]

- Errors: 20, -10, -10, toh SS_res = 400 + 100 + 100 = 600
- R² = 1 - 600/200 = **-2**

---

## 8. R² aur correlation

Simple linear regression mein (ek feature + intercept, train data par):

$$R^2 = r^2$$

$r$ = Pearson correlation. Jaise r = 0.9 toh R² = 0.81.

---

## 9. Limitations (important)

1. **Features badhane par R² kam nahi hota**, bekaar feature se bhi train R² thoda badh jata hai. Overfitting chhup sakti hai.
2. **R² akela nahi batata ki model sahi hai.** Curve wale data par line fit karke bhi R² high aa sakta hai, isliye residual plot bhi dekho.
3. **Outliers ke prati sensitive** (SS_res mein squaring).
4. **Test data par negative ho sakta hai.** Train par accha, test par negative = overfitting.
5. **Alag datasets ke beech compare mushkil**, kyunki baseline variance har dataset ki alag hoti hai.

### Adjusted R²

$$R^2_{adj} = 1 - (1 - R^2)\cdot\frac{n-1}{n-p-1}$$

$n$ = samples, $p$ = features. Bekaar feature add karne par yeh **gir sakta hai**, toh yeh zyada honest hai.

---

## 10. MSE, RMSE, MAE vs R²

| Metric | Kya batata hai | Range |
|---|---|---|
| MSE / RMSE / MAE | **Absolute** galti kitni hai | 0 se ∞ (kam = accha) |
| R² | Baseline ke mukable **relative** improvement | -∞ se 1 (zyada = accha) |

**Thumb rule:** dono saath report karo. RMSE = "typical galti kitni (unit mein)", R² = "model ne data ka kitna pattern pakda".

---

## Python check

```python
import numpy as np

y    = np.array([50, 30, 40])
yhat = np.array([45, 35, 40])

ss_res = np.sum((y - yhat) ** 2)
ss_tot = np.sum((y - y.mean()) ** 2)
r2 = 1 - ss_res / ss_tot
print(r2)  # 0.75
```

`yhat = np.array([30, 40, 50])` daal kar negative R² (-2) khud dekho.

---

## Quick revision

- Baseline = hamesha mean predict karna
- SS_res = model ki squared galti, SS_tot = baseline ki squared galti
- **R² = 1 - SS_res / SS_tot**
- R² = 1 perfect, 0 baseline jitna, negative = baseline se bura
- Features badhane par R² badhta hai, isliye **Adjusted R²** dekho
- R² (relative) aur RMSE (absolute) dono saath report karo
